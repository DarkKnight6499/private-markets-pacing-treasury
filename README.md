# Private markets pacing and treasury

`pm_pacing` is an offline Python library for private markets capital planning. It connects multi-vintage fund cash flows, annual commitment pacing, quarterly treasury funding, pre-trade policy checks, appraisal return adjustment, fund performance and whole-portfolio allocation.

All data are **synthetic**, generated by seeded code. Fund parameters, facility terms, stress scenarios, policy bands and allocation assumptions are **stylized**. Runtime calculations never access the network. NumPy and pandas are the only runtime dependencies; root finding, constrained optimization and tests use local implementations and the standard library.

## Run

From the project folder:

```text
python -m pip install -e .
python -m unittest discover -s tests -v
python examples/run_all.py
```

If NumPy and pandas are already installed, tests and examples also run directly without installing the package. The runner writes CSV and Markdown tables, policy JSON and full-precision summaries under [examples/output](examples/output/). No plotting packages are needed. [CI](.github/workflows/ci.yml) runs unittest and every example for each configured Python version.

```python
from pm_pacing import project_program
from pm_pacing.data import synthetic_vintages

funds, program = project_program(synthetic_vintages())
print(program[["year", "calls", "distributions", "nav", "unfunded"]])
```

## Methodology

The annual Yale fund model calls a fraction of unfunded commitments, grows opening NAV and distributes an age-dependent fraction of that grown NAV. The bow factor controls distribution timing. Its structure was verified in the [original fund-model working paper, capital contributions, distributions and NAV sections](https://allocatortraining.com/wp-content/uploads/2023/06/Illiquid-Alternative-Asset-Fund-Modeling-Takahashi-Alexander.pdf). Defaults cover buyout, venture, private credit and real assets. The program also includes faster-distributing secondaries and an immediately funded co-invest with no fee or carry assumed.

An explicit finite-life extension distributes terminal-period calls and cancels unused commitments. Both adjustments remain visible in the output. `project_fund(..., liquidate_terminal=False)` retains the published equations, including residual terminal calls. NAV and commitment conservation reconcile each period.

Annual pacing uses bisection, an annual commitment cap and future funding reservations. The public sleeve grows, pays calls and receives distributions; these transfers conserve total wealth. Target tracking is conditional on feasibility. Existing scheduled calls can force overshoot even with no new commitments, and status columns expose caps and funding constraints. Overcommitment is private NAV plus unfunded obligations divided by total portfolio NAV. Sensitivities separately vary distribution speed, net growth and call pace.

Treasury tracks facility draws, fixed-horizon repayments, interest, cash yield and a rolling gross call buffer. Required LP top-ups and pre-funding shortfalls are explicit. Distribution stress halves receipts; acceleration moves existing calls earlier while conserving their total. Opening cash coverage uses the peak cumulative stressed net outflow over the annual window, including existing debt maturities. Shortened terminal windows are identified. This is an internal measure, not a regulatory banking ratio.

Pre-trade policies are data, exported to JSON. Results identify each rule, pass/warn/fail status, measured exposure and inclusive limit. Rules cover strategy, vintage and geography bands, manager/fund/issuer concentration, sector/jurisdiction exclusions and unfunded limits. Complete issuer look-through is required. The conservative policy exposure basis is NAV plus unfunded divided by current total portfolio NAV.

The chosen unsmoothing method is an invertible first-order moving average specialization. Its weighted-return structure was verified in the [original smoothing paper, Section 4, equations for observed returns and normalized weights](https://www.mit.edu/~alo/Papers/JFE2004Pub.pdf). Our moment estimator solves the lag-correlation equation under independent true returns. Known coefficients recover the synthetic true series; estimated coefficients provide volatility and autocorrelation diagnostics. The previous recursive filter remains available, with its original Geltner equation attribution explicitly marked **stylized/unverified**. Main results use the verified moving average structure.

Fund performance includes custom conventional IRR, TVPI, DPI, RVPI and KS-PME. Every fund uses one shared synthetic public total return index aligned by calendar year. PME discounts distributions and calls by index levels, adding residual NAV when supplied. Its ratio was verified in the [original performance paper, Table VI description](https://onlinelibrary.wiley.com/doi/10.1111/j.1540-6261.2005.00780.x).

Allocation uses unsmoothed annual means and covariance in an exhaustive active-set mean-variance optimizer. Full investment, long-only weights, a maximum illiquid share and stressed annual liquidity coverage are enforced. KKT conditions verify convex optimality. The efficient frontier covers the upper return branch. Reported and adjusted allocations use identical policy constraints and are also evaluated on the same adjusted covariance.

[docs/methodology.md](docs/methodology.md) records equations, timing, source verification, assumptions and scope. Modules under [src/pm_pacing](src/pm_pacing/) separate modeling, pacing, treasury, compliance, performance, unsmoothing, optimization, numerical routines and synthetic data.

## Limitations

Cash flows are deterministic and annual; equal quarterly splits conceal intra-year timing risk. Secondaries are an accelerated sleeve without purchase pricing or transfer mechanics. Fees outside assumed net growth, carry waterfalls, taxes, currency effects, recycling, defaults, transaction costs and market impact are excluded.

Pacing is a greedy annual controller with future funding reservations, not a global schedule optimizer. Treasury assumes LP top-ups can be requested to construct the ladder; their required amounts remain explicit. Facility terms and compliance policies are stylized, and no regulatory parameter or legal compliance determination is asserted.

The moving average filter assumes independent true returns for estimation and a supplied initial lag. It rejects incompatible sample correlations and omits higher-order smoothing. Naive annualized covariance ignores residual serial dependence. The retained recursive filter's original-paper equation attribution remains stylized/unverified. Allocation liquidity coefficients are separate planning inputs, not fitted to the treasury ladder.

IRR accepts conventional cash flows only. The optimizer requires positive definite covariance and a small asset universe, with no automatic covariance repair. Static weights ignore trading restrictions and the time needed to reach private allocations. Local tests and examples ran successfully; configured hosted CI has not been executed in this sandbox.
